# Approved UI Examples

This document contains visual examples and patterns approved for this project.

Claude should use approved screens as visual references when creating new interfaces.

---

# How to use this document

When a screen is approved by the project owner:

1. Record the screen here.
2. Explain what makes the design correct.
3. Record patterns that should be reused.
4. Record elements that should NOT be copied if they are screen-specific.
